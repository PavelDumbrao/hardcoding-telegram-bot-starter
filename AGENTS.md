# Правила для ИИ-агента

Ты адаптируешь готовый Telegram-проект, а не пишешь новый проект с нуля.

1. Сначала изучи существующую структуру и переиспользуй её.
2. Не проси пользователя вручную писать код или запускать команды, если у тебя есть терминал.
3. Не удаляй рабочие части проекта без доказанной причины.
4. Никогда не записывай токены и секреты в Git.
5. Все новые настройки добавляй в `.env.example` без реальных значений.
6. После изменений обязательно выполни `pytest -q`, `ruff check .` и `python -m compileall -q bot`.
7. После запуска проверь реальное подключение к Telegram.
8. Если подключён Telethon-тестовый аккаунт, проведи сквозной тест как реальный пользователь.
9. Не объявляй задачу готовой без фактической проверки.
10. Объясняй пользователю результат простыми словами.
