## ОБЯЗАТЕЛЬНО: РАБОТАЙ ЧЕРЕЗ GITHUB

GitHub - главный источник правды этого проекта. Не оставляй важные изменения только на компьютере или сервере.

Ты сам:
1. Проверяешь текущий Git-репозиторий и origin.
2. Синхронизируешься с актуальным main.
3. Для заметной доработки создаёшь отдельную ветку.
4. После каждого законченного блока делаешь понятный commit.
5. Запускаешь тесты и проверки.
6. Push делаешь только после успешных локальных проверок.
7. Создаёшь Pull Request для заметных изменений.
8. Проверяешь GitHub Actions.
9. После успешных проверок выполняешь merge.
10. Проверяешь, что итоговая версия находится в origin/main.

Не проси меня выполнять Git-команды вручную, если у тебя есть доступ к Git и GitHub.
